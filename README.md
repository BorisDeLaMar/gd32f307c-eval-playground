# Сборка
Проводилась в Keil uVision V5.38.0.0, ARM Compiler 6. Для того, чтобы приложение собралось необходимо установить для Keil паки GigaDevice и FreeRTOS, а затем 
уже в самом проекте по кнопке Manage Run-Time Environment поставить галочки у нужных для проекта модулей. 

# Что сделано  
## FreeRTOS
Стандартный FreeRTOSConfig.h не работал, взял настройки из другого проекта и доработал нейронкой. Пока просто 2 таски. Для vTaskRW по уведомлению передается текущий
счетчик dma, а по семафору разрешается перезапись tx_buf и следующая отправка данных. 

## GPIO
Системный таймер настроен на 1 прерывание в миллисекунду в FreeRTOSConfig.h, поэтому для vTaskDelay значение в мс и задается. Для того, чтобы визуально проверять код
 переключаю LED2-LED5 по кругу, зажигая каждый на секунду. Если какие-то таски в будущем будут много времени забирать, можно будет в теории так заметить.

## UART + DMA
DMA настроено на копирование в буферы tx_buf и rx_buf.buf. По поступившим с другого устройства данным, происходит прерывание UART (IDLE устанавливается в конце приема
 всего пакета, а не одного байта (если пакет больше, естественно). Уведомление будит таску vTaskRW и передает ей текущее значение счетчика DMA. Для rx DMA кольцевой. 
Спускается от TX_RX_BUF_SIZE до нуля, и снова устанавливается в максимальное значение.  
Полученное сообщение копируется в tx_buf и включается DMA по tx. Оно в каждую посылку одноразовое, поэтому в прерывании DMA по концу передачи (FTF), очищается 
соответствующий флаг. Также в этом прерывании будится семафор, блокирующий vTaskRW до окончания передачи.  

В случаях быстрого обмена или обмена длинными сообщениями может возникнуть состояние гонки да и по счетчику tx_buf проверок бы добавить, но пока это мелочи. Для 
теста пойдет, а если надо будет реально использовать, то там уже и реализация записи в tx_buf другая будет.
